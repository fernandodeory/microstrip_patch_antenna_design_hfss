# 2.45 GHz microstrip patch antenna

Inset-fed patch antenna designed in HFSS on FR4, tuned to 2.45 GHz with a simulated S11 of -30.17 dB.

- [Design notebook](microstrip_design.ipynb): calculations, parameter sweeps and radiation patterns.
- [HFSS project](microstrip_2_4_ghz.aedt): antenna model.
- CSV files: exported simulation data.

The notebook includes saved plots. To rerun it, install NumPy and Matplotlib and keep the CSV files alongside it.
